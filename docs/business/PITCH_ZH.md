## 0. 一页摘要（Executive Summary）

**SharkQuant 是一个 AI 原生的一体化量化交易平台：把「行情 → AI 研究 → 策略编写/回测 → 交易机器人自动执行 → 实盘风控」装进一个产品里，让普通交易者一个人就能跑通过去需要一支小团队才能完成的量化工作流。**

- **产品**：已上线（sharkv2.com），覆盖 39 个功能页面、7 大类市场（加密/美股/港股/外汇/期货/A股/交易所股票）、8 家交易通道（Binance、OKX、Bitget、Bybit、Gate、HTX、IBKR、Alpaca）；内置 264 个量化因子（含 201 个 TA-Lib 0.8.1 因子）、58 个 MCP（Model Context Protocol）工具，AI 输出支持 11 种语言，界面支持中英双语。
- **模式**：订阅制（$19.9/月 · $199/年 · $499 终身）+ 用量额度（AI/回测等按次扣减）+ 指标市场平台分成 + 邀请返佣。支付体系（Stripe + 稳定币）已内置，待配置收款通道后全量开启。
- **时机（Why now）**：算法交易市场以 13.6% CAGR 增长（2026 年 $263 亿 → 2033 年 $643 亿）；AI Agent 生态在 2026 年爆发（MCP 服务器从发布时约 50 个增长到 2026 年二季度约 8,000–12,000 个），而「让 AI Agent 安全地接入交易」尚无标准答案——SharkQuant 的 Agent Gateway 已用「默认模拟盘 + 权限范围 + 限流 + 全量审计」给出了答案。
- **进展**：2026 年 8–10 月完成从旧版到 v5 分布式架构的升级、自建前端全量替换、双语文案与安全审计，生产环境稳定运行。

## 1. 问题：散户做量化，要过三重门

个人交易者想系统地做交易，面对的是三堵断墙：

| 环节 | 现状 | 痛点 |
|---|---|---|
| **数据** | 看盘用一个 App，宏观/新闻/情绪看另外三四个网站 | 信息碎片化，跨市场对比几乎做不到 |
| **研究** | 写策略 = 学 Python + 学一套框架 + 自己搭数据管道；回测平台与实盘平台割裂 | 门槛极高、链路断裂，90% 的人止步于"写得出策略但跑不起来" |
| **执行** | 盯盘下单靠手动，机器人工具要么只做加密、要么只做美股 | 情绪化交易、跨市场没有统一执行层 |

同时，现有工具各占一段：TradingView 强在图表、QuantConnect 强在机构级引擎、3Commas/Composer 强在单一市场的自动化——**没有人把「散户视角的全链路」做成一个产品**。2026 年 AI 能力爆发后，第一性问题变成：**AI 能不能把这三重门一次推平？**

**SharkQuant 的回答：能，而且是以「AI 原生」的方式。**

## 2. 解决方案：把量化工作流装进一个产品

SharkQuant 的六个模块构成一条闭环：

1. **看盘**：多市场实时行情（WebSocket 推送 5 秒级刷新）、K 线 + MA/BOLL/MACD/RSI 指标、情绪带（恐惧贪婪 / VIX / DXY）、全球市场（指数/外汇/加密/商品 + 热力图 + 财经日历）、**机会雷达**（规则扫描全市场找异动）。
2. **AI 研究**：AI 对话（流式、可传附件）、**快速分析**（多数据源聚合诊断单标的）、AI 报告（可导出 PDF、可分享链接）、**事件雷达**（AI 评估新闻对持仓/关注标的的影响）。
3. **策略**：脚本库（在线 IDE、编译校验、版本管理、可发布社区）、**AI 生成策略**（自然语言 → 可回测代码）、因子库（264 个因子，含 TA-Lib 0.8.1；支持因子研究与参数调整）、票池管理、参数寻优、策略 AI 助手。
4. **回测**：6 个月 BTC 双均线示例回测得出 **+34.99% 收益 / 1,104 个净值点**；引擎支持完整交易记录、胜率、夏普、最大回撤、相对基准等指标。（截图中策略页为真实回测数据）
5. **执行**：交易机器人（模板 + AI Smart 自然语言建机器人）、交易终端（下单/平仓/撤单含二次确认）、持仓/订单镜像、待处理订单队列、**7×24 策略运行时**（分布式 workers，租约 + 心跳 + 幂等保护）。
6. **连接**：8 家交易通道（6 家加密交易所 + IBKR/Alpaca 券商，覆盖美股/港股等传统市场）；**Agent Gateway**——把整个平台以 58 个 MCP 工具开放给 Cursor / Claude Code / Codex 等 AI Agent 调用。
7. **可治理的 AI 控制面（管理员）**：31 项 AI 技能与 66 个工具全部可视化——逐项启停、风险分级（read / write_draft / trading）、只读标记；提示词可渲染、可审计；技能支持安装/删除；preflight 一键体检（LLM · 数据源 · 搜索 · 券商 · 积分）。对团队与企业客户，AI 能力是**可见、可控、可审计的资产**，而不是黑盒。

## 3. 市场与时机

### 3.1 市场规模

- **算法交易市场**：2026 年 $263 亿 → 2033 年 $643 亿，CAGR **13.6%**（Grand View Research）；Mordor Intelligence 口径为 2026 年 $202 亿 → 2031 年 $295 亿；Technavio 预计 2026–2030 年增长 $239 亿，CAGR 16.7%。
- **在线交易平台市场**：2026 年 $126 亿 → 2031 年 $182 亿（CAGR 7.66%，Mordor Intelligence）；Precedence Research 给予 2026 年 $241 亿的更大口径。
- **用户基数**：仅中国 A 股投资者已超 **2.5 亿户**（个人占比 >99%，中国结算 2025 年报），2026 年 3 月单月新增开户 460 万户；全球零售投资者数以亿计。

SharkQuant 的目标人群不是全部零售投资者，而是其中 **「有量化意愿、缺工程能力」** 的活跃交易者（可编程/半自动用户）——这是一个高价值、高粘性的细分市场。监管趋严、AI 工具普及正在加速这个人群的软件付费意愿。

### 3.2 Why now

1. **AI Agent 生态爆发**：MCP 服务器数量从 2024 年发布时的约 50 个增长到 2026 年二季度的约 8,000–12,000 个；"让 Agent 干活"成为 2026 年企业软件的默认命题。
2. **Agent 的安全缺口 = 我们的差异化**：行业调查显示 47–53% 的企业遭遇过 AI Agent 越权或事故，仅约 23% 建立了正式的 Agent 身份体系。SharkQuant 已实现「Agent 令牌 + 五类权限范围 + 默认仅模拟盘 + 限流 + 全量审计」——**在「AI 帮你交易」这个最敏感的领域，安全设计就是产品**。
3. **LLM 能力与成本曲线**：推理成本持续下降，使「每个交易决策都有 AI 参与」在订阅价位上具备毛利空间。

## 6. 技术与壁垒

**架构（投资人可验证的事实）**：

- **分布式运行时**：18 个容器服务（PostgreSQL、双 Redis、Kafka、HTTP API、交易 worker、策略 dispatcher/evaluator、审计 worker、定时任务等）；PostgreSQL 为唯一真相源，Kafka 承载版本化事件，策略运行时与 HTTP 进程物理分离。
- **资金安全设计**：租约 + 心跳 + fencing + 幂等键防止重复下单；Agent 实盘需同时满足 4 个条件（令牌范围、显式授权、风险确认、非默认模式）；全量操作审计。
- **多租户**：4 级角色 + 细粒度权限 + agent 令牌租户隔离，已通过生产 QA（48 路由 × 双语回归）。
- **AI 能力**：LLM 提供商可插拔（OpenRouter 等），模型级回退可见化；AI 输出 11 种语言。
- **安全**：2026-10-11 安全审计——依赖 0 已知漏洞（OSV/npm 扫描 62 个依赖）、安全响应头全站配置、业务端口不对外暴露、CSP 已就位（观察期）。详见仓库 `docs/security/`。
- **扩展性路线**：V6 架构 RFC 已明确目标——**20,000 用户 / 100,000 并发策略**的横向运行时，首个模块已落地。
- **自托管选项**：一键安装脚本 + 容器镜像，面向对数据主权敏感的用户（差异化解锁机构/工作室客户）。

**壁垒逻辑**：全链路产品的复杂度（数据源合规、跨市场符号体系、订单状态机、风控与审计）构成工程壁垒；Agent 生态一旦形成（外部开发者用我们的 MCP 工具做策略/工具）将产生网络效应；多市场数据管道与 8 家交易通道的对接是时间换来的资产。
